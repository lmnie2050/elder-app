# elder-app
助理訓練
寫測試案例。 這是投報率最高的。你現在只有 15 題，目標是 100 到 200 題。對方只要想「長輩可能會說什麼」，寫成 userMessage，再寫一句「阿明應該怎麼回」。斷言的部分你來補，或是先用文字描述也行。

特別缺的類別：方言與台語夾雜、家人代操作（「我是他女兒」）、模糊的身體不適（「我這裡怪怪的」）、重複同一個問題、問阿明是不是真人。

補安全關鍵字。 safety.ts 裡那兩組詞是我憑常識寫的。長輩實際會怎麼描述胸痛？台語怎麼說？「歸身軀艱苦」「凍未條」這類講法我完全沒收。這件事需要的是生活經驗，不是技術。

寫標註規則手冊。 什麼樣的回應算好、算普通、算不能接受，要有明確標準。這份文件現在不寫，等資料累積起來就來不及了。

有點困難的

每日摘要模組。 從運動和飲食紀錄算出結構化摘要，純資料處理，跟 AI 完全無關。介面約定好之後可以獨立開發，這是第 3 階段最大的一塊。

個人檔案 schema 統一。 需要跟飲食 App 那邊對齊欄位定義，寫成一份共用規格。這件事卡著兩個子功能。
